# Estándar editorial de DevForge

DevForge ayuda a aprender, resolver problemas de trabajo y crecer profesionalmente con trato digno.

## Tutorial completo

- Define el objetivo, el nivel, los requisitos y el resultado que podrá comprobar el lector.
- Usa un escenario realista y datos ficticios. Identifica la arquitectura y los límites del ejemplo.
- Explica las decisiones del código. Incluye un caso exitoso, errores y un caso límite.
- Indica qué se comprobó, con qué comando o herramienta, y qué requiere el entorno de destino.
- Describe qué cambia al pasar a producción: permisos, secretos, tiempos de espera, reintentos y observabilidad cuando apliquen.
- Cierra con un ejercicio y una evidencia que se pueda documentar o compartir.

Referencia: el tutorial REST incluye código descargable y pruebas reproducibles con respuestas simuladas.

## Rutas, plantillas y guías laborales

- Ruta: fundamentos, práctica incremental, criterios de comprobación y proyecto con evidencia.
- Plantilla: cuándo usarla, datos ficticios, campos por confirmar y exportación. Separa los ejemplos de las decisiones reales del equipo.
- Guía laboral: situaciones concretas, frases que una persona puede adaptar y fuentes oficiales cuando proceda. Omite datos que identifiquen a terceros.
- Antes de publicar: revisa enlaces y ejemplos. Indica los requisitos de versión y qué se verificó. Actualiza el contenido cuando cambie su entorno.
